MANPREET CYBER SECURITY — PREMIUM WEBSITE

FILES
- index.html: Home page
- services.html: Services page
- tools.html: Educational tools page
- abouts.html: About/contact page
- login.html: Login/signup interface demo
- style.css: Shared design for every page

HOW TO RUN
1. Keep all six files in the same folder.
2. Open index.html in your browser.
3. Use the navigation menu to move between pages.
4. Edit YOUR_EMAIL@example.com in abouts.html to your own email.

IMPORTANT
- Login/signup is only a front-end demo. It does not authenticate users or save accounts.
- Password checker is a basic local estimate. Do not enter a real password.
- Security testing must only be performed on systems you own or have explicit permission to test.
- Google Fonts are loaded from the internet; system fonts are used as fallbacks.
